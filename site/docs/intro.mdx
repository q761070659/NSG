# 农夫乐事 Wiki

本站整理了服务器上「农夫乐事」整合内容的全部合成表与设备使用方式，数据直接来自服务端配置与插件源码：

- **合成表**：来自 CraftEngine 配置 `nong/configuration/recipes.yml` 的 **139 条**工作台与熔炉类配方、晒盐池的 **1 条**配方，从插件源码与蟹农配置提取的 **230 条**工作站配方，末地乐事的 **22 条**配方、蟹农的 **70 条**海鲜配方，以及山茶花的 **1 条**茶壶配方，共 **463 条**。
- **设备玩法**：来自 `NongStoveIgniter` 插件（版本 1.6.35），提供烹饪锅、煎锅、砧板、小木桶、木盆五类烹饪设备；捕蟹笼、椰子树与海鲜装备来自 `CeXie` 插件。
- **物品与分类**：来自 `categories.yml` 与语言文件 `langs/zh_cn.yml`。

## 内容构成

整合内容分为四个部分，在游戏内的物品浏览器中也是独立分类：

| 分类 | 说明 | 代表内容 |
| --- | --- | --- |
| 农夫乐事 | 基础农业与厨房 | 炉灶、烹饪锅、砧板、煎锅、卷心菜、番茄、洋葱、稻米 |
| 暖风丰年 | 进阶农耕与发酵 | 小木桶、木盆、树液采集器、葡萄、玉米、花生、奶酪、果酱、酒类 |
| 末地乐事 | 末地主题烹饪 | 末地石炉灶、金烹饪锅、金煎锅、肥皂、末地作物与料理 |
| 蟹农乐事 | 海鲜捕捞与加工 | 捕蟹笼、椰子树、螃蟹、虾、蛤蜊与珍珠、桶装海鲜、海鲜装备 |

## 五分钟入门路线

1. **做一把刀**。刀是砧板加工的前提，也是获得草秆、生肉切片的关键工具。最基础的是燧石刀。

   <RecipeFor item="default:flint_knife" />

2. **搭一个炉灶**。炉灶是烹饪锅与煎锅的热源，需要用打火石点燃。

   <RecipeFor item="default:stove" />

3. **做烹饪锅**。烹饪锅是产出料理最多的设备，可做汤、炖菜、意面、果酱等。

   <RecipeFor item="default:cooking_pot" />

4. **做砧板**，把生肉切成肉片、把作物切成食材。

   <RecipeFor item="default:cutting_board" />

5. **把烹饪锅放在点燃的炉灶上**，右键打开界面放入食材与容器（碗、瓶），等待烹饪完成。

   详见 [烹饪锅使用方式](/stations/cooking-pot)。

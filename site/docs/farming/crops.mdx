# 作物与野外采集

整合内容新增的作物大多要**先在野外找到野生版本**，采集后才能拿到种子开始种植。本页告诉你去哪找。

## 野生作物在哪找

野生作物会在世界生成时刷在对应生物群系的地表。找到后右键或破坏即可采集。

| 野生作物 | 生物群系 |
| --- | --- |
| 野生卷心菜 | 沙滩、积雪沙滩 |
| 野生甜菜根 | 沙滩、积雪沙滩 |
| 野生洋葱 | 平原、向日葵平原、草甸、樱花树林、森林、繁花森林、白桦森林、原始白桦森林、黑森林 |
| 野生胡萝卜 | 同野生洋葱 |
| 野生马铃薯 | 针叶林、原始松木针叶林、原始云杉针叶林、风袭丘陵、风袭森林、雪林 |
| 野生稻米 | 河流、沼泽、红树林沼泽、丛林、稀疏丛林、竹林 |
| 野生番茄 | 沙漠、热带草原、热带高原、风袭热带草原、恶地、繁茂恶地、被风蚀的恶地 |
| 野生棉花 | 同野生番茄 |
| 野生绿葡萄 | 沙漠、热带草原系、丛林系、恶地系 |
| 野生红葡萄 | 雪原、冰刺之地、积雪针叶林、雪林、积雪山坡、尖峭山峰、冰封山峰、裸岩山峰、冻河、冻洋、深层冻洋 |
| 野生花生 | 平原、森林系、草甸、樱花树林、沼泽系、河流 |
| 蓝莓灌木 | 平原、向日葵平原、森林系、沼泽系、河流、草甸、樱花树林 |
| 棕色蘑菇菌落 | 蘑菇岛 |
| 红色蘑菇菌落 | 蘑菇岛 |
| 各色菊花（8 色） | 平原、森林、繁花森林、草甸 |

:::tip[找作物的思路]
- 想要**主粮**（卷心菜、洋葱、胡萝卜、马铃薯）：去平原、森林、沙滩、针叶林。
- 想要**稻米**：去河流或沼泽。
- 想要**番茄和棉花**：去沙漠或热带草原。
- 想要**红葡萄**：只在寒冷生物群系；**绿葡萄**只在炎热生物群系。
- 想要**蘑菇菌落**：只有蘑菇岛。
:::

## 右键收获

大部分自定义作物成熟后可以**直接右键收获**，不用破坏方块：收获后作物会回退到早期生长阶段继续长，等于免去重新种植。

举例：

- **蓝莓灌木**：成熟（age 3）右键掉落 **2–3 个**蓝莓，回退到 age 1。直接破坏 age 2 掉 1–2 个、age 3 掉 2–3 个，时运每级追加随机数量。
- **棉花**：成熟右键掉落 **1–2 个**棉花。未成熟时可以用骨粉催熟。
- **玉米**：age 达到收获线右键掉落玉米，完全成熟时掉 **2 个**，否则 1 个。

## 番茄爬绳

番茄可以顺着绳子往上长，实现立体种植：

1. 在地上种植番茄 `default:tomatoes`。
2. 在番茄上方搭**绳子**。
3. 番茄会沿绳子向上生长，最多长 **3 格**挂绳番茄。
4. 右键成熟的挂绳番茄收获。

地面那株番茄不计入 3 格上限。收获挂绳番茄会解锁成就**采田艹加**。

## 葡萄架

葡萄需要**架子**才能种植。有三种架子：普通架子、竹架、去皮竹架。把葡萄种在架子上即可。

## 樱桃

用**非剪刀**工具破坏**樱花树叶**时，有 **2%** 概率额外掉落一个樱桃 `default:cherry`。原版树叶掉落不受影响。

樱桃可以做樱桃果酱、樱桃酒、樱桃汁。

## 银星作物

银星作物（银星卷心菜、银星番茄、银星洋葱、银星葡萄、银星花生、银星玉米、银星蓝莓、银星覆盆子）是**高品质变种**，在正常收获时有机会获得。它们是游戏内的收藏与炫耀目标。
